# Portfolio fonts

Latin WOFF2 files are self-hosted from the official Google Fonts CSS API and fonts.gstatic.com. Inter, Jost and the retained Space Grotesk files are variable fonts; Space Mono is regular. Jost is the active display family, Inter the UI family, and Space Mono the metadata/code family. Each family is distributed under its included SIL Open Font License 1.1 notice. Original files are unmodified.

See sources.json for download URLs, weights, retrieval date, file sizes, and SHA-256 hashes.

Jost upstream: https://github.com/indestructible-type/Jost .

Upstream projects: [Inter](https://github.com/rsms/inter), [Space Grotesk](https://github.com/floriankarsten/space-grotesk), and [Space Mono](https://github.com/googlefonts/spacemono).

License notice wording is retained; line endings and trailing whitespace are normalized for the repository.
