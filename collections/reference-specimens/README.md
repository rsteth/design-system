# Independent reference specimens

Three original, neutral studies inspired by selected secondary design analyses. These are isolated from app-owned catalogs. Nothing here is an official brand kit or a verified reconstruction.

Each study exposes components, an interactive filtering pattern, and a screen via `?view=`. The shared adapter acknowledges only the single supported theme. Run them in the workbench allow-scripts sandbox. No storage, external fonts, image downloads, submission, or live service requests occur. Dialog drafts reset on reopening; filters are reversible.

`manifest.json` is the importer's registration contract. `provenance.evidence` names unverified source claims; `provenance.inferred` identifies original decisions. Exact source colors are preserved where selected, not silently replaced with a universal palette. Source asset references are deliberately excluded.
