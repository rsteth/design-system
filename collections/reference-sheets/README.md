# Independent visual reference sheets

These are authored, unofficial interpretations of pinned VoltAgent analysis, not product components or reproductions. No logos, imagery or font binaries are used. System-font substitutes, semantic markup, sample content, focus outlines and local interactions are original additions.

`index.html` and `patterns.html` inside each study directory and `report.json` are generated by `npm run references:import`. Do not edit those outputs. `sheet.css` and `sheet.mjs` are the shared recipe shell/runtime. `patterns.css` and `patterns.mjs` implement three shared original patterns: overview/actions, searchable selection, and editable preferences. `tooling/reference-patterns.mjs` composes these from each sheet’s palette, bounded spacing/radii, system-font substitutes, and explicitly reported fallbacks. Nothing is sent or stored by their local interactions. The compiler uses typed CSS allowlists and own-property reference resolution; source HTML, CSS programs and Markdown are never executed. The pages prohibit external resources with CSP and require no runtime data fetching.

All 84 sheets are registered only in reference collections. The existing curated specimens are separate fixture options. Missing fields, unsupported declarations and withheld assets must not be inferred to be complete. Exact source citations remain in inert `template.source-evidence` metadata and the linked `report.json`, not visible labels. The single pinned-source link stays available; the workbench's sandbox blocks popups, so use the surrounding Sources section or Open source fixture to follow links from a standalone sheet.

The complete MIT analysis notice remains in each original reference directory. No rights in brand assets, fonts or trademarks are implied. The project's existing license status is unchanged.

All 84 studies register the standard pattern fixture (252 illustrative patterns total). These are not captured screens, official patterns, or claims about original product behavior. Screens is disabled in the workbench for studies with no registered screen fixture; the three existing curated screen studies remain separate.

Run `node tests/workbench/patterns-browser.mjs` with the repository’s configured Playwright module to check every pattern at desktop/mobile sizes, repeated actions, invalid/empty states, cancel/undo, collection switching and history. `tests/workbench/artifacts/warp-patterns/` holds the latest local QA evidence.
