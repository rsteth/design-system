# Reference workbench implementation and remaining gaps

Local implementation on 2026-11-07, feature/design-foundation. No publication, commits, application updates or external-site embeds. The prior reference-workbench-plan.md remains intact.

## Delivered

- 84 source-linked visual sheets using one shared compiler and renderer.
- 2,135 recipe specimens: 2,086 from 74 structured sources, 49 selected recipes from ten manual prose normalizations. Recipes include variants, style-only surfaces and withheld-asset placeholders; this is not a count of production components.
- Palette, substituted typography, spacing, radii, interactive neutral button/field/navigation templates, cards, tables and styles. Recipe name/type filters and property-level source evidence.
- Nine additional neutral Carbon Core input/state specimens demonstrate official documented dimensions and semantics, separately from the original IBM website study. Two additional CTA specimens use dated default-desktop observations of Runway and SAP. Runway/SAP/IBM have evidence supplements with explicit source categories and gaps.
- Original source documents/hashes, own-app registries/tokens/vendors and nine curated fixtures preserved. Only the blank starter's shared engine copy is synchronized with the shell update.
- Uniform Open original site control. 72 recorded current identities, nine explicitly unverified/blocked candidates, three unavailable URLs. Current identity does not establish historical design fidelity.

## Missing detail

- All analyses remain secondary and unverified. System fonts replace named typefaces. Logos, photographs, proprietary illustrations and font files are deliberately absent.
- The ten prose normalizations select only evidence-backed literals, not complete systems. Ranges, estimates, unclear alternatives, motion and unspecified states remain unimplemented. Runway has the sparsest four partial recipes.
- Of the initial 34 unsupported declarations, 24 are now recovered from explicit prose in the same pinned sources: 17 bottom borders and seven SAP pixel heights. Ten remain unresolved: five inactive transparent-border ambiguities and five SAP numeric heights without explicit units. Every recovery is hash-locked and visibly cites its supporting prose; no generic inference rule was added.
- Only Stripe, Linear and Dell 1996 retain curated patterns/screens. The other 81 have visual foundations and recipe sheets, not invented full product screens. Empty pattern/screen sections remain explicit.
- Original URL is unresolved for 1win and historical Dell 1996/Nintendo 2001. No modern website is substituted as historical evidence. Bugatti, Ferrari, Meta, Mydealz, Pinterest, Sentry, SpaceX, Spotify and Tesla are labeled candidate links according to existing homepage evidence.
- Local action/select/input behavior, semantic templates, responsive bounds and focus outlines are authored interpretations. Full state semantics, keyboard interaction models and brand fidelity are not established by the sources.

- npm run check: schema/syntax/skin/import determinism, unit tests and static build.
- reference-sheets-browser.mjs: 168 actual shell/sandbox mounts, responsive and 390px, no external requests, uncaught errors, invalid emitted CSS or horizontal overflow. All-study filtering/reset; repeated local controls on five contrasting studies.
- browser.mjs: existing engine/starter regression, isolation, themes, navigation, inventory and mobile layout.
- self-collection.mjs: shell palette, real engine reuse, recursion boundaries, empty starter and desktop/mobile.
- reference-browser.mjs: all 84 library entries, repeated navigation/search, Robin separation, race/history handling, hostile text/URLs and nine original curated mounts at both widths.
- reference-specimens-browser.mjs: 18 original curated desktop/mobile cases, filters, validation, repeated reset, Cancel/Escape and focus return.

Browser tests use the already-installed Playwright and Chrome in fresh isolated profiles. No installation or signed-in profile used. These checks are not a full accessibility or official visual-fidelity certification. Application-owned servers/suites were not rerun; no app source or vendor snapshots changed.
